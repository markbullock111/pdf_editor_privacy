Editing text

Tapping text does nothing

Turn on the mode first: Tools ▸ Edit ▸ Edit Text. A bar appears saying "Tap any text to edit it". Without it, tapping selects text rather than editing it.

"No editable text there"

The page is a scan — a picture of a document with no text layer. Run Tools ▸ Insert ▸ Recognize Text first. That adds an invisible text layer and leaves the page looking exactly the same.

The replacement changed font

PDFs usually embed only the letters a document actually uses. If you type a character the document's own font does not contain, there is no glyph to draw, so the app substitutes a standard font matched to the original's weight and style — and tells you when it does. Reusing letters already on the page keeps the original font.

Long replacements overlap the next words

Replacing text keeps the original spacing, so text noticeably longer than what it replaced can run into what follows. Shorter or similar-length edits sit correctly.

Redaction

Is redacted content really gone?

Yes. The characters are deleted from the page's content stream and the pixels are erased from any image underneath, then a black box is drawn on top. Copying, searching or extracting text from the result will not recover it. This is the difference between redaction and drawing a rectangle.

Save a copy first. Redaction is meant to be irreversible. Undo works while the document is open, but once saved and closed the content is gone — which is the point.

Converting

The Word file lost my layout

A PDF stores glyphs at coordinates; it does not record paragraphs, headings or tables. Those are reconstructed from where text sits on the page. Tables come across as editable Word tables and pictures are embedded, including cells whose text wraps over several lines. What does not survive is a page set in two or more columns: it is flattened into a single column in reading order. Each format states its limits in the app before you commit.

Images did not come across

The Word export embeds the pictures from each page. The PowerPoint export carries text only — to keep the visuals there, export as PNG or JPEG images instead. A picture drawn smaller than about 8 pt is treated as a rule or a spacer and left out.

"This document has no text layer to convert"

Same as above — it is a scan. Run Recognize Text first.

Files and storage

Where are my documents?

Wherever you opened them from. The app has no library of its own and no cloud storage. It opens documents in place through the Files app, so iCloud Drive, Dropbox, Google Drive and OneDrive all work if you have those apps installed.

Do my documents get uploaded?

No. Everything, including conversion and text recognition, runs on your device, and the app contains no code that uploads a file. The only thing it talks to the internet for is Apple's subscription check, which knows nothing about your documents — see the privacy policy.

A password-protected PDF will not open

Enter its password when prompted. If you do not have it, the document cannot be opened — the password is what encrypts it, and there is no way around that. Some PDFs also carry an owner password restricting printing or copying; Apple's PDF engine does not enforce those, so the app does not claim to either.

Purchases

What does Pro unlock?

Editing, conversion, redaction, annotations, signatures, page management, scanning and text recognition. Reading, searching, navigating and sharing are free and always will be.

I bought Pro but it is locked

Tap Restore Purchases on the purchase screen, and check you are signed in with the same Apple Account you bought with. Purchases are tied to that account, not to the device.

Is it a subscription?

Yes — PDF Studio Pro is US$9.99 per year and renews automatically until you cancel. Cancel any time in Settings ▸ your name ▸ Subscriptions on iPhone and iPad, or App Store ▸ your name ▸ Account Settings on Mac; you keep Pro until the period you have paid for runs out. Reading stays free whether you subscribe or not, and Family Sharing is supported. Full terms are on the terms page.

How do I cancel?

Open Settings in the app and tap Manage Subscription, which takes you to Apple's subscription list. We cannot cancel it for you — only Apple can, because only Apple holds the billing relationship.

Refunds

Purchases go through Apple, so refunds do too: reportaproblem.apple.com. Do email first if something is not working — a fix is usually quicker.

Accessibility

The app supports VoiceOver, Dynamic Type, Dark Mode and full keyboard navigation on Mac. Read Aloud uses the system voice and works offline. If something is hard to use with assistive technology, please tell me — those reports get priority.
